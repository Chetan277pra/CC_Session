You can perform the following operation any (possibly zero) number of times: </p><ul> <li> You can choose a position $$$i$$$ and delete a digit $$$d$$$ on the $$$i$$$-th position. Then insert the digit $$$\min{(d + 1, 9)}$$$ on any position (at the beginning, at the end or in between any two adjacent digits). </li></ul><p>What is the lexicographically smallest string you can get by performing these operations?</p><p>A string $$$a$$$ is lexicographically smaller than a string $$$b$$$ of the same length if and only if the following holds: </p><ul> <li> in the first position where $$$a$$$ and $$$b$$$ differ, the string $$$a$$$ has a smaller digit than the corresponding digit in $$$b$$$. </li></ul></div><div class="input-specification"><div class="section-title">Input</div><p>The first line contains a single integer $$$t$$$ ($$$1 \le t \le 10^4$$$) — the number of test cases.
